# Outbreak v.2.00

A 2D strategy/survival game. You control a country or region during a global
bio-crisis (bacteria / virus / zombie outbreak). Survive, expand, develop the
cure, and eradicate the disease.

Built as a code-first simulation. Engine (Godot) will be added later.

## Roadmap

- **Mode 1 (current):** You are the state. Fight the outbreak.
- **Mode 2 (later):** You are the disease. Destroy humanity.
